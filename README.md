# 魔都人生

一款可以把人生分岔寄给朋友的网页喜剧。18岁进城，60岁回看；六个上海街区，开局五连抽，三格年度行动，工作、约会、邻里和自己的日子互相牵动。

公开试玩：[modulife.pages.dev](https://modulife.pages.dev/) · 源码：[GitHub](https://github.com/joeymilano/modu-life)

## 本地试玩

使用 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

打开终端显示的 Local 地址。正式构建用 `npm run build`，产物在 `dist/`。这是静态网页，运行时不需要模型服务或用户账号；公开试玩部署在 Cloudflare Pages，访问无需登录。

## 已做的玩法

- 18—60岁六个人生章节；42个年度回合，每年三格行动。每月收入、住房和生活费在年末统一结算。
- 五槽40张开局卡，两个免费重抽机会，五种人生目标；挑战链接保留种子、开局卡与目标。
- 六城区、24地标，角色能点击地面或用WASD/方向键移动，建筑避让与寻路；也可以直接进入已选地点。
- 八条职业与三轮面试。晋升需要在岗时间、本事和工作评审。33 岁缩编和 45 岁工作变动会改变工资、工时或岗位，自由职业和生意的收入会波动。
- 24名人物，八名成年恋爱候选。对话按人物偏好结算吸引、信任与承诺；疏于维护关系会流失信任。
- 外滩的四元柠檬水有五轮激光和一把伞。首页能直接挑战，赛后的小票可下载或发给朋友躲同一轮红光。人生模式里，过关后可以去江边对账，从小票上的决定另开时间线。
- 人民公园相亲角可以挂牌、把资料改成真话，或替汪阿姨收伞。三个决定会带来三场不同的回访，可另开时间线，也可以把回访分享给朋友。[直接试玩相亲角](https://modulife.pages.dev/#story=park-umbrella)。
- 租房三处查坑和约会对话都有替代办法与资源代价。
- 跨年故事用条件、标记和后续节点保留旧选择。失业、缺钱、疲惫有恢复办法；不因一次翻车直接清档。
- 新开局从上海南站的三条消息选起。看房、顶班和送箱子各有一张独立的写实剧情剧照，接下来的年度事件会记住当时选了什么。后来也会遇到退租、换岗、陪家人复诊和接手早点摊。
- 默认街景使用纪实摄影风格的上海街区画面。点画面下方的地点可以直接过去，切到「3D 地图」仍能走路、看地标和切换夜景。
- 「我的人生」可以回到最近24个剧情选择，另开一条从当时状态继续的支线。每个存档最多保留八条时间线，原线和支线可以来回切换。
- 「重走别人的人生」是单独的模式。这里可把一到五幕写成带分支的车票。玩家走完可以回到某个选择重走，也能把回执和原来的走法放在一起看。现实题可直接向朋友征集自己的解法。
- 自动存档、三个手动存档位、档案导入导出、人生分享图片。
- 首次完整加载后可离线继续。正式构建注册Service Worker，开发模式不缓存。

网络梗在游戏中作原创情节改编。人物、插画、程序化模型、动画与台词均为本项目制作。

## 代码分层

- `src/game/`：类型、内容、事件、纯规则引擎、存档、声音和分享。
- `src/components/`：原创城市模型、场景交互、寻路、人物头像与小游戏。
- `public/models/manifest.json`：十个GLB模型槽，其中东方明珠、武康大楼、绿裙角色和夜猫子使用 Tripo GLB。

渲染与规则分开。漫游不改变年龄与经济；确认活动才消耗时间。所有活动、对话与小游戏结果最终经过统一规则结算。

## 验证

```sh
npm test
npm run build
python3 scripts/browser_smoke.py
```

浏览器脚本需要Python Playwright与本机Chrome，以及先启动的本地开发服务。脚本默认访问 `http://localhost:5173/`；覆盖桌面和手机尺寸、激光、面试、约会、年末结算、租房、存档与六区切换。它属于浏览器模拟测试，不能代替iPhone或Android真机性能验收。

## 后续模型升级

外滩和陆家嘴加载东方明珠，安福路加载武康大楼。开局选择女性「惊艳全场」可旋转预览绿裙模型，进城后也会使用该模型。夜猫子邮筒保留3D特写和来信互动。模型制作见 [Tripo 模型接入说明](TRIPO_MODELS.md)。


## 人物与美术

开局可以选择女性或男性，以及普通耐看、颇有姿色、惊艳全场三档形象，共六套独立人物美术。高颜值女性采用明确成年、性感时装的设计。外观会保存在自动存档、手动存档、导出档案和同手牌挑战链接中；旧版缺少外观字段的存档自动迁移为男性／普通耐看。

颜值对开局腔势和第一次认识恋爱对象的好感有小幅加成，信任、承诺与关系结局继续由相处决定。性别不限制可认识的对象。地图里的玩家也随性别与颜值切换发型和衣着。绿裙模型目前是静态网格，会随角色移动与转向。

人物立绘、40 张开局牌、小游戏场景和街景使用内置 ImageGen 生成的纪实摄影风格素材。运行时文件在 `public/art/`，提示词在 `art/portrait-and-origin-prompts.json` 、`art/shanghai-streets.json`、`art/street-cast-stills.json` 、`art/pearl-stills.json` 、`art/cast-followups.json` 和 `art/neighborhood-stills.json`。初版素材和提示词归档在 `art/source/` 与 `art/prompts.json`。24 位常驻角色的头像与立绘来自同一张图，点开通讯录的头像可以看大图和最近的共同经历。

八名约会对象各有一次三幕初见和一场后续剧情。初见的决定会改变下一次可以选的走法。再见一面的选择会留在时间线，也能连同剧照做成车票发给朋友。陆嘉和何亮会提起第一晚发生的事。16 张约会剧照和生成提示词见 `public/art/dates/` 与 `art/date-stills.json`。

六种玩家形象在 32 岁和 53 岁换上新的头像与立绘。第一晚实际见过毛小毛、何亮或陆嘉的人，59 岁会遇到对应的重逢。60 岁结局会并排展示进城照和现在的照片。导出的人生卡带有同手牌挑战二维码。12 张年龄立绘和 9 张场景图的提示词见 `art/ageing-and-endings.json`。职业变动和面试的 7 张剧照提示词见 `art/work-stills.json`。

`python3 scripts/art_acceptance.py` 覆盖六种形象、162 个美术文件、保存／导出／旧档迁移、约会剧照、看房线索和手机约会流程。


## 公开发布

GitHub `main` 分支自动发布到 Cloudflare Pages：

- 项目名：`modulife`
- 正式网址：`https://modulife.pages.dev`
- 构建：`npm test && npm run build`
- 输出：`dist/`
- Node.js：22
- 每次推送触发 Cloudflare 构建；GitHub Actions 同时检查测试和构建。无需在 GitHub 配置 Cloudflare 密钥。

需要手动发布时，在同一 Cloudflare 账号登录后运行 `npm run deploy`。`wrangler.jsonc` 是当前发布配置。游戏仅使用静态文件，没有后端函数或付费模型调用。

存档和车票保存在当前浏览器。邀请与回执可通过链接或 JSON 文件交换，拿到链接或文件的人都能打开。若之前在另一地址玩过，请在原地址导出人生档案，再到新地址的「存档」中导入。

Tripo模型实际加载、桌面／手机／夜景、来信扣行动与存档验收：`python3 scripts/tripo_acceptance.py`。设置 `GAME_URL=https://modulife.pages.dev/` 可检查公开版并验证离线模型与3D特写。
