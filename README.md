# 魔都人生

一款单人网页人生喜剧。18岁进城，60岁回看；六个写意上海街区，开局五连抽，三格年度行动，工作、约会、邻里和自己的日子互相牵动。

## 本地试玩

使用 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

打开终端显示的 Local 地址。正式构建用 `npm run build`，产物在 `dist/`。这是静态网页，运行时不需要模型服务或用户账号；Sites 试玩地址沿用平台的私密访问设置。

## 已做的玩法

- 18—60岁六个人生章节；42个年度回合，每年三格行动。每月收入、住房和生活费在年末统一结算。
- 五槽40张开局卡，两个免费重抽机会，五种人生目标；挑战链接保留种子、开局卡与目标。
- 六城区、24地标，角色能点击地面或用WASD/方向键移动，建筑避让与寻路；也可以直接进入已选地点。
- 八条职业与晋升；三轮面试。不同工作有不同压力，自由职业和生意的收入会波动。
- 24名人物，八名成年恋爱候选。对话按人物偏好结算吸引、信任与承诺；疏于维护关系会流失信任。
- 东方明珠五轮激光闪避、租房三处查坑、相亲对话；每项都有替代办法与资源代价。
- 跨年故事用条件、标记和后续节点保留旧选择。失业、缺钱、疲惫有恢复办法；不因一次翻车直接清档。
- 自动存档、三个手动存档位、档案导入导出、人生分享图片。
- 首次完整加载后可离线继续。正式构建注册Service Worker，开发模式不缓存。

内容来源研究在父目录 `research/`。梗的出处和原创游戏改编分开记录；游戏人物、插画、程序化模型、动画与台词均采用原创实现。

## 代码分层

- `src/game/`：类型、内容、事件、纯规则引擎、存档、声音和分享。
- `src/components/`：原创城市模型、场景交互、寻路、人物头像与小游戏。
- `public/models/manifest.json`：八个可替换GLB模型槽。接Tripo时不必重写玩法。

渲染与规则分开。漫游不改变年龄与经济；确认活动才消耗时间。所有活动、对话与小游戏结果最终经过统一规则结算。

## 验证

```sh
npm test
npm run build
python3 scripts/browser_smoke.py
```

浏览器脚本需要Python Playwright与本机Chrome，以及先启动的本地开发服务。脚本默认访问 `http://localhost:5173/`；覆盖桌面和手机尺寸、激光、面试、约会、年末结算、租房、存档与六区切换。它属于浏览器模拟测试，不能代替iPhone或Android真机性能验收。
