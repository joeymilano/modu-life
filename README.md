# 魔都人生

一款单人网页人生喜剧。18岁进城，60岁回看；六个写意上海街区，开局五连抽，三格年度行动，工作、约会、邻里和自己的日子互相牵动。

公开试玩：[modulife.pages.dev](https://modulife.pages.dev/) · 源码：[GitHub](https://github.com/joeymilano/modu-life)

## 本地试玩

使用 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

打开终端显示的 Local 地址。正式构建用 `npm run build`，产物在 `dist/`。这是静态网页，运行时不需要模型服务或用户账号；公开试玩部署在 Cloudflare Pages，访问无需登录。

## 已做的玩法

- 18—60岁六个人生章节；42个年度回合，每年三格行动。每月收入、住房和生活费在年末统一结算。
- 五槽40张开局卡，两个免费重抽机会，五种人生目标；挑战链接保留种子、开局卡与目标。
- 六城区、24地标，角色能点击地面或用WASD/方向键移动，建筑避让与寻路；也可以直接进入已选地点。
- 八条职业与晋升；三轮面试。不同工作有不同压力，自由职业和生意的收入会波动。
- 24名人物，八名成年恋爱候选。对话按人物偏好结算吸引、信任与承诺；疏于维护关系会流失信任。
- 东方明珠五轮激光闪避、租房三处查坑、相亲对话；每项都有替代办法与资源代价。
- 跨年故事用条件、标记和后续节点保留旧选择。失业、缺钱、疲惫有恢复办法；不因一次翻车直接清档。
- 自动存档、三个手动存档位、档案导入导出、人生分享图片。
- 首次完整加载后可离线继续。正式构建注册Service Worker，开发模式不缓存。

网络梗在游戏中作原创情节改编。人物、插画、程序化模型、动画与台词均为本项目制作。

## 代码分层

- `src/game/`：类型、内容、事件、纯规则引擎、存档、声音和分享。
- `src/components/`：原创城市模型、场景交互、寻路、人物头像与小游戏。
- `public/models/manifest.json`：九个GLB模型槽，其中夜猫子已导入，八个地标可继续替换。

渲染与规则分开。漫游不改变年龄与经济；确认活动才消耗时间。所有活动、对话与小游戏结果最终经过统一规则结算。

## 验证

```sh
npm test
npm run build
python3 scripts/browser_smoke.py
```

浏览器脚本需要Python Playwright与本机Chrome，以及先启动的本地开发服务。脚本默认访问 `http://localhost:5173/`；覆盖桌面和手机尺寸、激光、面试、约会、年末结算、租房、存档与六区切换。它属于浏览器模拟测试，不能代替iPhone或Android真机性能验收。

## 后续模型升级

详见 [Tripo模型接入说明](TRIPO_MODELS.md)。建筑与玩家仍使用原创程序化3D模型；外滩已导入现有Tripo猫头鹰，带可旋转的3D特写和邮筒来信互动。尚未调用Tripo API新生成模型。接口密钥应只存在开发环境，不能写进网页或模型清单。


## 人物与生成美术（第二版）

开局可以选择女性或男性，以及普通耐看、颇有姿色、惊艳全场三档形象，共六套独立人物美术。高颜值女性采用明确成年、性感时装的设计。外观会保存在自动存档、手动存档、导出档案和同手牌挑战链接中；旧版缺少外观字段的存档自动迁移为男性／普通耐看。

颜值对开局腔势和第一次认识恋爱对象的好感有小幅加成，信任、承诺与关系结局继续由相处决定。性别不限制可认识的对象。地图里的玩家也随性别与颜值切换发型和衣着，目前仍是程序几何角色，尚未接入 Tripo 人物模型。

人物立绘、40张开局牌、八类剧情插画、首页、看房和怪谈背景由内置 Image generation 工具生成。运行时使用压缩的 `public/art/*.webp`，完整原图保存在 `art/source/*.png`，逐张提示词与拼图顺序见 `art/prompts.json` 与 `art/README.md`。UI图标保留为矢量，以保证小尺寸清晰。

新增浏览器验收：`python3 scripts/art_acceptance.py`，覆盖六种形象、14个美术文件、保存／导出／旧档迁移、约会大图和手机约会流程。


## 公开发布

GitHub `main` 分支自动发布到 Cloudflare Pages：

- 项目名：`modulife`
- 正式网址：`https://modulife.pages.dev`
- 构建：`npm test && npm run build`
- 输出：`dist/`
- Node.js：22
- 每次推送触发 Cloudflare 构建；GitHub Actions 同时检查测试和构建。无需在 GitHub 配置 Cloudflare 密钥。

需要手动发布时，在同一 Cloudflare 账号登录后运行 `npm run deploy`。`wrangler.jsonc` 是当前发布配置。游戏仅使用静态文件，没有后端函数或付费模型调用。

存档保存在浏览器和域名对应的本地空间中。若之前在另一地址玩过，请在原地址导出人生档案，再到新地址的「存档」中导入。

Tripo模型实际加载、桌面／手机／夜景、来信扣行动与存档验收：`python3 scripts/tripo_acceptance.py`。设置 `GAME_URL=https://modulife.pages.dev/` 可检查公开版并验证离线模型与3D特写。
