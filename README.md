# 魔都人生

一款可以把人生分岔寄给朋友的网页喜剧。18岁进城，60岁回看；六个上海街区，开局五连抽，三格年度行动，工作、约会、邻里和自己的日子互相牵动。

公开试玩：[modulife.pages.dev](https://modulife.pages.dev/) · 源码：[GitHub](https://github.com/joeymilano/modu-life)

## 本地试玩

使用 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

打开终端显示的 Local 地址。正式构建用 `npm run build`，产物在 `dist/`。这是静态网页，运行时不需要模型服务或用户账号；公开试玩部署在 Cloudflare Pages，访问无需登录。

## 已做的玩法

- 18—60 岁六个人生章节。每年三格行动，年底统一结算。记事本可以翻回新结算的账，对照两条时间线同一岁的余额，也能保存带同手牌二维码的年末照片。
- 首页「选定出身」可直接玩日结工或顶级富二代。日结工从 ¥780 和短租床位起步，待结班费单列。顶级富二代新开局有 ¥6,000 万个人可动用资金，家里按月代付陆家嘴服务公寓的指定账单。个人资金、家里代付和公司采购各走各的账。36 岁遇到同一桩搬仓，两种出身分别处理通勤和公司预算。46 岁以后有各自的排班或公司往来款，59 岁的收尾会留进相册。[搬仓短篇](https://modulife.pages.dev/#story=move-warehouse)可以从两边开走。
- 21 至 22 岁，两条线遇到同一家仓配公司的宿舍续租。日结工可以接白班住员工宿舍，富二代可以动用个人存款接股权，再参与利润分配表决。[《宿舍这笔钱》](https://modulife.pages.dev/#story=staff-bed)可以换视角查看表决如何落到工人的住处。人物、合同、金额和结果均为虚构。参考了[闵行区一线劳动者的床位租住案例](https://www.shanghai.gov.cn/nw4411/20241011/60878c7998fe4ef286af2cf23b728279.html)和[公司法关于表决与利润分配的条文](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_067c072db6ef4679a2e0180996be4cf8.html)。
- 八位可约会角色在碰面、桌边和道别各有剧照，第一次见面做过的事会改变下次的对白和做法。
- 开局分牌桌和选角。五槽 40 张开局卡，两次重抽机会。每次可比较两张同类牌，换上才扣一次。抽完可复制同手牌链接或下载带二维码的开局牌照，保留换牌结果、外观和目标。
- 五种特定手牌会在 18 岁带来独立插曲，可以开支线。
- 六城区、24地标，角色能点击地面或用WASD/方向键移动，建筑避让与寻路；也可以直接进入已选地点。
- 八条职业与三轮面试。晋升需要在岗时间、本事和工作评审。33 岁缩编和 45 岁工作变动会改变工资、工时或岗位，自由职业和生意的收入会波动。
- 24名人物，八名成年恋爱候选。对话按人物偏好结算吸引、信任与承诺；疏于维护关系会流失信任。
- 中年后可以从街区消息或通讯录再见吴师傅、方姐和沈经理。三个人都会记得上次怎么收场，通讯录会留下当时的决定。方姐的押金故事也可以[直接试玩](https://modulife.pages.dev/#story=fang-deposit)。
- [四元柠檬水保卫战](https://modulife.pages.dev/pearl/)在蜜雪冰城的小摊旁开打，雪王站在步道边。八轮，一把伞，虚线是倒影，脚下有斜纹就得换道。外滩试玩能选严可或孙阿宝，结算小票记下每一轮。旧挑战链接保留原来的五、六或七轮。人生模式里，过关后可以去江边对账，从小票上的决定另开时间线。
- [黄河路先庆哪一桩](https://modulife.pages.dev/#story=huanghe-toast)可以走汽水和包厢两条路，周五各有一张结账剧照。在「我的人生」21 岁以后去人民广场，可以翻菜单夹，找到 ¥48 拼桌的第三种庆功。[在上海碰到谁](https://modulife.pages.dev/#story=shanghai-cameos)有外白渡桥与安福路的两场虚构街头偶遇。
- 约人界面可按当前城区筛选。八位约会角色在通讯录、约人和见面时使用对应年龄的照片，32 岁和 53 岁换到下一阶段。年轻时初次见面仍有不同的街景和饭桌镜头。
- 通讯录可以切换全部、见过和有消息。吴师傅、方姐、沈经理等人的来信会排在前面，从照片点进去可以赴约。24 位联系人都有三个年龄段的头像和立绘，毛小毛、老妈等八位熟人的重拍提示词见 `art/support-casting.json`。
- 点右上角扬声器可以开关游戏声音。配乐《Apero Hour》由 [Kevin MacLeod](https://incompetech.com/music/royalty-free/index.html?isrc=USUAN1700070) 提供，采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)，游戏中降低了音量并转码。
- 人民公园相亲角可以挂牌、把资料改成真话，或替汪阿姨收伞。可以把号码留给汪阿姨代转。挂牌或改简历的路线后来会遇到群截图，对照两版能找出最早转图的人。[直接试玩转发事件](https://modulife.pages.dev/#story=paper-forward)。[直接试玩相亲角](https://modulife.pages.dev/#story=park-umbrella)。
- 租房三处查坑和约会对话都有替代办法与资源代价。
- 跨年故事用条件、标记和后续节点保留旧选择。失业、缺钱、疲惫有恢复办法；不因一次翻车直接清档。
- 在上海南站，六种开局外观各有一张到站剧照。读三条消息时可以在到站剧照和对方发的照片之间切换，再决定回谁。看房、顶班和拿橘子都能检查现场物件，找出第三种处理方式。第二年会接着当时的选择往下走。后来也会遇到退租、换岗、陪家人复诊和接手早点摊。
- 默认街景使用纪实摄影风格的上海街区画面。六个街区都有一件实物可以点开，陆家嘴、安福路和莘庄可以隔年回去。画面下方的地点仍可直接访问，切到「3D 地图」也能走路、看地标和切换夜景。[直接试玩安福路的折椅](https://modulife.pages.dev/#story=queue-cup)。
- 「我的人生」可以回到最近24个剧情选择，另开一条从当时状态继续的支线。每个存档最多保留八条时间线，原线和支线可以来回切换。
- 「重走别人的人生」是单独的模式。这里可把一到五幕写成带分支的车票，也能把现实题发给朋友。走完两条不同路线后，可以在回执里对照从哪一步分开、后来各发生了什么，再把两条路存成一张图。内置故事的对照图可扫码从头玩。末班车和东方明珠故事的七张结局剧照见 `art/parallel-ending-stills.json`。
- 自动存档、三个手动存档位、档案导入导出、人生分享图片。
- 首页和已打开的内容会在联网时缓存。准备断网玩时，打开「存档」，点「下载离线包」备齐剧情剧照、3D 地图、音乐和小游戏。正式构建提供离线缓存。

网络梗在游戏中作原创情节改编。人物、插画、程序化模型、动画与台词均为本项目制作。

## 代码分层

- `src/game/`：类型、内容、事件、纯规则引擎、存档、声音和分享。
- `src/components/`：原创城市模型、场景交互、寻路、人物头像与小游戏。
- `public/models/manifest.json`：十个GLB模型槽，其中东方明珠、武康大楼、绿裙角色和夜猫子使用 Tripo GLB。

渲染与规则分开。漫游不改变年龄与经济；确认活动才消耗时间。所有活动、对话与小游戏结果最终经过统一规则结算。

## 验证

```sh
npm test
npm run build
python3 scripts/browser_smoke.py
python3 scripts/arrival_acceptance.py
```

浏览器脚本需要Python Playwright与本机Chrome，以及先启动的本地开发服务。脚本默认访问 `http://localhost:5173/`；覆盖桌面和手机尺寸、激光、面试、约会、年末结算、租房、存档与六区切换。它属于浏览器模拟测试，不能代替iPhone或Android真机性能验收。启动正式预览后可运行 `python3 scripts/offline_acceptance.py`，验证首次缓存、离线读档、3D 地标和断点续下载。

到站走查还需要 `python3 -m playwright install webkit`。它会在 Chrome 和 WebKit 的桌面、手机尺寸上读完三条消息，逐一回复三个联系人并玩到 19 岁，覆盖在待回复时刷新后继续存档。可通过 `GAME_URL` 指定要验收的网址。

## 后续模型升级

外滩和陆家嘴加载东方明珠，安福路加载武康大楼。开局选择女性「惊艳全场」可旋转预览绿裙模型，进城后也会使用该模型。夜猫子邮筒保留3D特写和来信互动。模型制作见 [Tripo 模型接入说明](TRIPO_MODELS.md)。

外滩 3D 地图把海关钟楼和和平饭店摆在浦西，东方明珠、金茂、环球金融中心和上海中心隔江在浦东。地图采用游戏比例，玩家可走到浦西码头并触发轮渡故事。石墙、铜顶贴图和建筑参考见 `art/bund-bank-materials.json`。

安福路有梧桐、砖墙和路边咖啡桌。人民广场从上博圆顶走到相亲角和棋摊。张江的研发楼用玻璃廊桥连起来，莘庄的站房旁摆了带灯的小吃摊。四个街区采用游戏比例，贴图提示词和参考见 `art/district-model-materials.json`。


## 人物与美术

开局可以选择女性或男性，以及普通耐看、颇有姿色、惊艳全场三档形象，共六套独立人物美术。高颜值女性采用明确成年、性感时装的设计。外观会保存在自动存档、手动存档、导出档案和同手牌挑战链接中；旧版缺少外观字段的存档自动迁移为男性／普通耐看。

颜值对开局腔势和第一次认识恋爱对象的好感有小幅加成，信任、承诺与关系结局继续由相处决定。性别不限制可认识的对象。地图里的玩家也随性别与颜值切换发型和衣着。绿裙模型目前是静态网格，会随角色移动与转向。

人物立绘、40 张开局牌、小游戏场景和街景使用内置 ImageGen 生成的纪实摄影风格素材。运行时文件在 `public/art/`，提示词在 `art/portrait-and-origin-prompts.json` 、`art/shanghai-streets.json`、`art/street-cast-stills.json` 、`art/pearl-stills.json` 、`art/cast-followups.json` 、`art/neighborhood-stills.json` 和 `art/opening-stills.json`。初版素材和提示词归档在 `art/source/` 与 `art/prompts.json`。24 位常驻角色的头像与立绘来自同一张图，点开通讯录的头像可以看大图和最近的共同经历。

八名约会对象各有一次三幕初见和一场后续剧情。初见的决定会改变下一次可以选的走法。再见一面的选择会留在时间线，也能连同剧照做成车票发给朋友。陆嘉和何亮会提起第一晚发生的事。生成提示词见 `art/date-stills.json` 和 `art/date-table-stills.json`。

六种玩家形象各有 18、46、60 岁的照片，选角时可以来回看，进入人生仍从 18 岁开始。游戏中在 32 岁和 53 岁更换年龄段头像，点头像可以看当年的立绘。第一晚实际见过毛小毛、何亮或陆嘉的人，59 岁会遇到对应的重逢。60 岁结局可以翻开三张照片，导出的人生卡带有同手牌挑战二维码。当前立绘提示词和头像裁切见 `art/player-casting.json`。结局场景图见 `art/ageing-and-endings.json`，职业变动和面试的剧照见 `art/work-stills.json`。

`python3 scripts/art_acceptance.py` 覆盖六种形象、162 个美术文件、保存／导出／旧档迁移、约会剧照、看房线索和手机约会流程。


## 公开发布

GitHub `main` 分支自动发布到 Cloudflare Pages：

- 项目名：`modulife`
- 正式网址：`https://modulife.pages.dev`
- 构建：`npm test && npm run build`
- 输出：`dist/`
- Node.js：22
- 每次推送触发 Cloudflare 构建；GitHub Actions 同时检查测试和构建。无需在 GitHub 配置 Cloudflare 密钥。

需要手动发布时，在同一 Cloudflare 账号登录后运行 `npm run deploy`。`wrangler.jsonc` 是当前发布配置。游戏仅使用静态文件，没有后端函数或付费模型调用。

存档和车票保存在当前浏览器。邀请与回执可通过链接或 JSON 文件交换，拿到链接或文件的人都能打开。若之前在另一地址玩过，请在原地址导出人生档案，再到新地址的「存档」中导入。

Tripo模型实际加载、桌面／手机／夜景、来信扣行动与存档验收：`python3 scripts/tripo_acceptance.py`。设置 `GAME_URL=https://modulife.pages.dev/` 可检查公开版并验证离线模型与3D特写。
