# 《魔都人生》真人电影感预览

2026-11-15。继续此前的《浦江破局》版本，按用户选定的「真人写实电影感」升级首页、四线出身卡、三幕剧情演出和系统线人物。主线仍发生在1992—1999年的上海。

试玩：[电影感预览](https://pujiang-preview.modulife.pages.dev/)；本轮固定版本：[75fc3718](https://75fc3718.modulife.pages.dev/)。选择「选择出身 → 系统流」体验完整八章。其他三个出身也有各自新版开场。

## 已实现

- **8张原创写实场景**：顾桥与停电舞台、陆嘉开场、吴师傅与末班车、锦江家宴、许舟与路线图、周闻与维修台、顾桥饭局、展销现场。全组WebP合计1,043,632字节。原始PNG保留在工作区`outputs/pujiang-cinema/source/`。
- **33幕台词与构图**：三条普通开篇加系统八章，每幕配置人物台词、神态、焦点、道具与观察提示。不同幕使用人物切换或同一画面的焦点变化。表现采用生成静帧与有限的轻微镜头运动，并非AI生成视频。
- **对话与决定同步**：左侧人物近景／手机上方剧情画面，右侧／下方保留完整正文与所有选项。分幕进度显示已经完成及当前所处的幕次。失利和部分完成也有对应的收场台词。
- **现场观察**：可展开看纸票、工牌、路线图等可见物件，不消耗回合，不直接显示「识人」专属的隐藏诉求。
- **人情账**：查看本场选择累计造成的实际信任变化；采用规则层的关系增量，只读展示。结算后不把已入账的增量再加一次。
- **能力画面**：蓝灰色的主角专属提示与时代场景分离，23岁明确显示离线。支持「静止画面」，并尊重系统的减少动态效果设置。
- **人物一致性**：陆嘉、吴师傅、沈经理的图片以原角色资产为面貌参考；顾桥、许舟、周闻建立固定新形象。三位新联系人使用「初识时的照片」，不把青年照声称为老年即时形象。
- **前情更具体**：按章节显示共同订单、任务抄本、愿意回场的伙伴和展销成果，减少每年重复同一段「第一笔奖金」提示。

画面资源与分镜在`src/game/pujiangCinema.ts`，展示在`PujiangStage.tsx`与`pujiang-cinema.css`。存档结构、结算规则、奖励上限与每周排位接口没有因这次视觉升级而变更。
