# 《浦江破局》实现与验收记录

本轮交付四线开篇、系统流18—25岁八章、六项能力与配装、六区委托，以及26—60岁的结局回访。新游戏进入新版，既有档案保持旧版规则。

试玩入口：[浦江破局预览](https://pujiang-preview.modulife.pages.dev/)。本页记录剧情规则首版，固定版本：[e82c62e1](https://e82c62e1.modulife.pages.dev/)；2026-11-15的后续电影感版本及280项验证见[画面升级记录](pujiang-cinema-validation.md)。选择「系统流」进入八章主线。预览使用独立站点存储；正式站点的旧存档不会自动出现在这里，可从「存档」导出后导入。没有新版标记的旧档仍进入原剧情。

## 本轮内容

| 出身 | 开篇 | 两类主要解法 | 后续影响 |
|---|---|---|---|
| 初到上海／随机出身 | 今晚，谁来开场 | 自己撑起节目／组织伙伴转场 | 19岁不同回访收益，23岁兑现承诺后的备用方案 |
| 日结工 | 末班车只剩一个位子 | 重排卸货岗位／组织短驳班组 | 吴师傅信任、19岁排班回访、23岁援助 |
| 顶级富二代 | 有钱，也要有人听你的 | 身份与样机成果／出资留住团队 | 保留六千万资金起点及资产系统，19岁客户回访 |
| 系统流 | 停电之后，倒计时亮了 | 恢复现场／共同救场 | 首单最高八万，共享则个人奖励减半并积累伙伴信任 |

系统篇每章三幕、三次必选决定，失利仍可推进。八章的年份依次为1992—1999年；主线不扣年度三格行动。六区委托各两幕，开始时扣一格，每条只能结算一次。阅读、暂停和能力预览不消耗选择回合。

可实测的跨章变化：

- 18岁救场中与许舟协作、分出奖励，提高19岁的调车援助可用性。
- 19岁独家成功报酬十二万，共同接单成功报酬六万；共同订单会打开20岁的团队入场和联合试演。
- 21岁顾桥会针对已展示的配装；换成尚未展示的能力，会改变同一选项的效果。
- 22岁强留许舟会关闭23岁的回场援助；尊重她的安排则保留合作可能。
- 23岁无异能交付成功，24岁增加一份调度，能改变三处危机的资源分配。
- 25岁独立掌舵、合伙共营、带人退出都能选择；完成质量另受既往成果、关系与履约影响。26、28、34、38、41、49、57岁回访及60岁后日谈会按去向变化。

## 能力与结算

从Lv.1、一个能力点开始，主线第2、4、6、8章结算后升级至Lv.2—5。每章首次结算获得一个能力点，失败照常获得。基础能力一点，进阶能力两点并要求对应基础和Lv.3；Lv.2起两个装备位。

| 路线 | 基础 | 进阶 |
|---|---|---|
| 洞察 | 识人：揭示当幕隐藏诉求 | 推演：指定一个选项，只预览该项直接后果 |
| 专长 | 借技：临时满足当幕专业要求 | 融会：开启组合操作；普通场景可节省调度 |
| 协作 | 寻援：获得援助信息与一份调度 | 同频：有愿意合作的伙伴时，额外选择现场补位或协调人手 |

每项已装备能力每场限用一次，进场后锁定配置。23岁提前告知全场异能离线。能力不代替决定，不使用异能、资金不足或连续失利均有可继续的路径。

现金、属性、关系、标记和奖励账本统一在最后一幕结算。回执展示选定操作的实际回复、现金奖励、净收支、付出现金、成长、人物信任和下一章影响。八章与六委托的设定最大奖励总和为294.8万元，另有300万元规则上限。

## 兼容与边界

- `GameState.storyEdition`为可选字段；只有新开局写入2。旧档缺失它时不迁移剧情，旧对决与旧系统兑换继续原逻辑。
- `episode`保存幕次决定、能力目标及使用记录、入场配装、最终回执；`systemProgress`保存已学能力、装备及累计新增奖励。
- 自动存档、手动存档、导入导出及时间线都使用现有档案容器。章节的分支引用增加`episode`类型，比较岔路时纳入前序幕次，避免把同章三幕误认成同一选择。
- 只补缺失的顾桥、周闻、许舟默认联系人状态；缺失既有联系人仍判为损坏档案。
- 新章节在年度推进与快进前有统一拦截；刷新已结算回执不能再领奖。
- 本轮没有修改排位计分、排位接口、数据库结构或部署绑定。预览沿用已有的预览数据库配置，没有执行迁移或写入排位成绩。
- 剧情规则首版复用已有四张年代场景，三个新增通讯录条目使用姓名印记；后续电影感版本已升级为原创写实场景和固定人物照片。既有街区、支线与3D地图仍可能出现现代素材，年代检查范围为新增剧情。

## 验证结果

`npm test`：**31个测试文件、276项通过**，相对253项基线新增23项。`npm run build`通过；`git diff --check`通过。

新增规则验收包括四线成功与失利、逐章两类成功解法、三个成功结局及60岁续玩、无现金且不用能力的连续失利、六能力与混搭、锁定配装、使用次数、动态对手、无异能挑战、关系与跨章调度、独家与合作报酬差异、奖励封顶、重复结算拒绝、快进停止、导入续玩、分支独立和旧档兼容。既有排位用例及固定80分回归仍通过。

正式构建在Chromium、WebKit分别以1440×900及390×844尺寸完成：

- 四线各一次成功与一次失利，共32次开篇路径，结算后刷新不重复加钱。
- 四套完整系统流程，八章连续至25岁，每章保留三格行动。
- 每套通过真实时间线按钮进入三个成功结局，再做六区委托，继续至60岁。
- 配装、能力目标选择、双击能力不重复使用、自动保存、手动存入、导出导入、刷新后保留能力消耗、真实分支回放。
- 无页面脚本异常，无页面或剧情容器横向溢出。

脚本为`python3 scripts/pujiang_acceptance.py`，可用`GAME_URL`和`PW_BROWSER=webkit`切换目标。走查使用独立浏览器环境和真实界面点击，不注入游戏进度。完整报告与截图在`outputs/pujiang/chromium/`、`outputs/pujiang/webkit/`；在线预览的抽查单独保存在`outputs/pujiang/online/`。浏览器手机尺寸模拟不等同于iPhone或Android真机验收。

在线固定版本已复测1440像素富二代开篇与390像素系统开篇，刷新后奖励保持一致。预览别名的实际入口文件为`main-B6rUvuhI.js`，与本次构建一致；另在在线手机尺寸下完成借技解锁接线、能力双击、存入手动档、推进一幕后载回、继续结算八万元与刷新复核。在线抽查无脚本异常；八章至60岁的完整矩阵运行于同一正式构建的本地预览。

## 时长与年代检查
