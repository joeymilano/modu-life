# 魔都人生 · 第二版美术

本轮使用内置 Image generation 工具生成，风格为半写实沪上都市电影美术。成人角色、真实材质、墨绿阴影与铜金灯光贯穿人物和场景。

- `source/`：完整生成 PNG 原图，后续改图和3D参考从这里取。
- `../public/art/`：同名 WebP 发行文件，画面内容不变，仅压缩编码。
- `prompts.json`：本轮最终提示词、文件名、拼图规格和用途。

| 文件 | 内容与顺序 |
| --- | --- |
| player-female / player-male | 横排三格：普通耐看、颇有姿色、惊艳全场 |
| romance-female | 二乘二：许小雯、林佳、乔敏、陆嘉 |
| romance-male | 二乘二：周宁、陈恺、杨帆、何亮 |
| supporting-cast | 四乘四：汪阿姨、顾爷叔、老妈、老爸；毛小毛、唐圆、高原、沈经理；方姐、吴师傅、余老师、费启；严可、孙阿宝、祁清、宋奶奶 |
| cards-birth / wealth / talent / ties / secrets | 每张四列两行，对应内容库中同类别八张牌的顺序 |
| story-scenes | 四列两行：事业、约会、歇息、学习；住房、社交、经营、怪谈 |
| shanghai-night | 首页主视觉 |
| rental-room | 可交互看房背景 |
| pearl-laser | 可交互东方明珠怪谈背景 |

所有拼图按从左到右、从上到下读取。界面通过固定网格裁切展示，无运行时生图调用。人物作品使用成人时装设计；普通、耐看和高颜值形象为不同人物，并非滤镜替色。

现有Tripo猫头鹰已作为外滩夜猫子邮筒导入。城市建筑与玩家尚未替换为Tripo模型；详见根目录 `TRIPO_MODELS.md`。
